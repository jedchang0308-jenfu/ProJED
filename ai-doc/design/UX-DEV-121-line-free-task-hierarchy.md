# UX-DEV-121｜OKR 無線任務階層設計稿

- 狀態：Rejected / Superseded by `UX-DEV-121-owned-connector-task-hierarchy.md`
- 日期：2026-09-14
- 範圍：OKR 模式的固定任務名稱欄與跨欄任務比對
- 視覺稿：本方向經使用者否決；有線樹狀表格仍為既定方向。

## UX Intent

- 任務／結果：使用者可在 1～2 秒內辨識任務深度、可否收合、所屬根任務，並沿同一列比對目的、會議紀錄、負責人與狀態。
- 主物件／主焦點：一列任務；任務名稱欄是固定的辨識錨點。
- 預設刪除：所有長距離 hierarchy continuation rail、elbow 與跨列關聯線。
- 保留舉證：父任務 disclosure arrow 必須保留，否則無法辨識可收合狀態；根任務群組底色必須保留，否則跨根任務的分界只剩資料順序。
- 非語言修復：固定深度縮排、專屬箭頭槽、根任務群組列、父任務 subtree 聚焦、整列 hover／selected 狀態。
- 風險與驗證：深度 0～4、長標題、收合後、水平捲動後、rowSpan owner cell、鍵盤焦點與 1024px viewport。

## 建議方案：無線樹狀表格

### 1. 刪除所有常駐階層關聯線

階層不再依賴使用者沿著垂直線追蹤。每列只用「深度起點」與「父任務箭頭」表示樹狀結構，避免線段跨越多列後產生錯誤歸屬。

### 2. 每層固定 20px 深度步距

- Level 0：`12px` 起點。
- Level 1：`32px` 起點。
- Level 2：`52px` 起點。
- Level 3：`72px` 起點。
- Level 4：`92px` 起點。

同一深度的任務名稱必須共用相同文字起點；不可依標題長度或是否有子任務改變。

### 3. disclosure arrow 使用獨立 24px 槽

- 展開父任務：向下箭頭。
- 收合父任務：向右箭頭。
- 葉節點：保留等寬空槽，不顯示箭頭。

箭頭只承擔「是否有子任務／是否展開」語意，不再同時充當關聯線端點。

### 4. 根任務採看板式群組標頭

Level 0 使用低對比群組底色、較高字重與群組前 `8px` 留白。其作用等同看板欄位標頭：先辨識工作群組，再閱讀群組內任務。一般子任務列不建立卡片或外框。

### 5. 父任務按需顯示 subtree 範圍

滑鼠 hover、鍵盤 focus 或長按父任務時：父任務使用較明確底色，其所有可見後代只在任務名稱欄套用淡底色。離開後立即恢復。這個狀態直接回答「哪些任務屬於它」，不增加常駐線條。

### 6. 任務資訊比對使用整列狀態

- Hover：該任務實際擁有的列單元格使用極淡背景，協助目光跨欄移動。
- Selected：該任務實際擁有的列單元格使用單一持續背景，直到選取其他任務。
- 父任務的 rowSpan owner cell 維持原本跨列範圍與底色，不偽裝成子任務資料。
- 狀態顏色只出現在狀態文字，不與階層顏色混用。

### 7. 固定欄與資料語意維持

- 任務名稱欄固定在資料表最左側，建議桌面寬度 `296px`。
- 其他欄位由同一個 X 軸捲動容器移動。
- 水平捲動離開原點後，固定欄右側才出現淡陰影，表示欄位邊界。
- 原生 table、rowSpan、內容 owner／covered 語意維持；設計不複製父任務內容到子任務列。

## 狀態規格

| 狀態 | 任務欄 | 其他欄位 | 目的 |
| --- | --- | --- | --- |
| 一般 | 深度縮排＋必要箭頭 | 純文字與既有欄位值 | 最低噪音閱讀 |
| Parent hover／focus | 父列較深、後代淡底 | 不變 | 看清 subtree 歸屬 |
| Row hover | 淡背景 | 同列自有欄位淡背景；rowSpan owner 維持 | 跨欄比對 |
| Selected | 單一持續背景 | 同列自有欄位持續背景；rowSpan owner 維持 | 維持比較上下文 |
| Collapsed | 右箭頭，後代隱藏 | 對應列同步隱藏 | 關係由狀態變化確認 |

## Acceptance Criteria

- [ ] 畫面中不存在任何常駐垂直 hierarchy rail 或 elbow。
- [ ] 隨機抽取任務時，可由固定文字起點判斷 level 0～4。
- [ ] 只有具有可見後代的任務顯示 disclosure arrow。
- [ ] hover／focus 任一父任務時，只有該任務與其可見後代被標示。
- [ ] hover／selected 任務時，目光可沿同一列辨識至少任務名稱、負責人與狀態。
- [ ] 水平捲動後任務名稱欄保持固定，其他欄位只有一個 X 軸 scroll owner。
- [ ] 原生 rowSpan 與 owner／covered content 模型維持。
- [ ] 1024px 桌面 viewport、鍵盤流程與深度 4 長標題可完成主要比對任務。
